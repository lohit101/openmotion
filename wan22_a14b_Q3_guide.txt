F) START COMFYUI + ZROK (LOW VRAM MODE)
-------------------------------
# 1) Go to ComfyUI
%cd /content/ComfyUI

# 2) Start ComfyUI (background is OK)
!nohup python main.py --listen 0.0.0.0 --port 8188 --lowvram > /content/comfy.log 2>&1 &

# 3) Install zrok if missing
!command -v zrok || curl -sSf https://get.openziti.io/install.bash | bash -s zrok

# 4) Ensure PATH
import os, time
os.environ["PATH"] += ":/usr/local/bin:/usr/bin:/bin"

# 6) Reset zrok state (IMPORTANT FIX)
!zrok disable || true

# 5) Enable zrok ONCE
ZROK_TOKEN = "YOUR_TOKEN"
!zrok enable {ZROK_TOKEN}

time.sleep(3)

# 6) Start zrok share (FOREGROUND = MORE STABLE)
print("\n🌍 Public URL will appear below:\n")
!zrok share public http://127.0.0.1:8188
