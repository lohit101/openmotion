# Remotion controls and retired SCAIL-2 files

New creation exposes only the current Viggle workspace. The redundant model selector is replaced by a compact model caption. Reusing a historical SCAIL draft shows an explicit “Use Remotion for a new video” action; it does not silently convert that draft. Legacy adapter, framing and motion-transfer controls are absent. The frame-edit prompt appears only when automatic frame preparation actually uses it. Prepared-frame video sampling has no text-prompt input.

SCAIL-2 / Wan weights and adapters are excluded from available downloads, Extras, per-module controls and Download all. The server rejects new individual or module download requests containing a retired file before probing the GPU or starting a transfer. Shared current files are retained in the active catalog by destination, rather than retiring a shared dependency by model name.

Historical catalog metadata, compilers and paid-run recovery remain. Existing retired weights and partials appear under **Retired files** in Downloads only when stored or involved in an unresolved transfer. Their actual bytes count toward storage. Explicit deletion remains available; this update deletes no models. No Download/Retry action is offered for those rows.

A saved queued retired-model download cannot restart. An uncertain active transfer remains protected until the original rental can be checked; recovery only requests cancellation of that transfer. An unconfirmed stop remains busy and protects the idle-pause guard. Installed and partial files are kept.

All **559 Studio tests**, TypeScript checking and the production build passed. The historical comparison compiled 165 eligible saved graphs identically; another 129 completed/terminal states kept their pre-existing compiler rejection, with zero differences from the preceding commit. The guarded local deployment preserved **367 job records and both drafts**. A live retired-file request returned HTTP 400 without creating work. Available browser providers could not be opened, so a new native browser visual/interaction review is not claimed.

The GPU stayed stopped throughout this cleanup and deployment. Video quality experiments and their costs are recorded separately; this change does not enable an experimental identity recipe. See [validation](validation/remotion-retirement-20261104.json).
