# External videos in the clip editor

2026-10-28. Native file drops on the timeline accept multiple videos, indicate the insertion position, preserve file order, and share the existing direct trim/reorder/export controls. Add videos opens a multiple-file picker. Local upload reports real byte progress and then metadata preparation; cancel/unmount aborts the upload and prevents pending clips from being inserted. Supported imports are available in the Imported source tab across reloads. Draft state also flushes on navigation/page hide.

Timeline clips now contain exactly one `jobId` or `assetId`. Legacy job-only drafts and receipts remain valid. Namespaced asset routing never records an upload as a generated job, and submitted arbitrary paths are still rejected. Export receipts retain the real source type and range; imported-only results use the existing local-edit presentation, without fabricated AI seed/model/hardware details. Originals remain unchanged. Phone right-angle rotations use decoded orientation and avoid stream-copy; incompatible pixel aspect/custom rotations and variable/discontinuous frame rates have explicit errors. Other codecs get a cached H.264 browser preview; lossless export still reads the original file.

Missing/ambiguous source identities are rejected. Existing source files/drafts and offline GPU state remain unchanged.
