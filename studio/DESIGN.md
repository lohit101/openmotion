# Recast Studio

A media-first product dashboard for character replacement and motion transfer. Higgsfield is a reference for composition, not a copied brand or feature set.

Design read: compact creative tools, large media canvas, real generation library. DESIGN_VARIANCE 5, MOTION_INTENSITY 3, VISUAL_DENSITY 6. Predictable controls and low motion support repeated work. Radix primitives provide accessible dialogs, menus, switches and selects; native CSS owns the visual language. Phosphor is the only icon family. Self-hosted Geist is the typeface.

Use a consistent charcoal theme, with a light theme sharing the same hierarchy. Pale lime is the only brand accent. Error colors are semantic. Controls use 8px corners, media surfaces 12px corners, status chips full rounding. Type: 12px metadata, 13-14px controls, 18-24px workspace headings. Navigation 64px tall. Sidebar 72px, editor 352px. Below 1000px, narrow the editor; below 760px, stack the editor and preview with a compact top navigation.

The application uses actual prior GPU results as library content. No stock gallery, fabricated credits, fake metrics, timer-based progress or simulated online GPU state. Progress shows the current ComfyUI stage and its reported counter. Loading weights and exporting remain indeterminate when no counter is supplied. Offline editing, uploads, local playback and library use remain available.

On the dashboard, source/reference badges, video controls and progress overlays are functional product UI. Landing-page hero, logo-wall and marketing-section rules do not apply. Respect reduced motion, accessible focus rings and labelled controls. Verify dark/light states and the narrow layout before delivery.
